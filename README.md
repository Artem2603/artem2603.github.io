# Вход в MyLLM

Страница-переадресатор для Mini App MyLLM. Кнопка ⚡ в Telegram ведёт сюда,
а страница за секунду находит открытую дверь приложения и уходит на неё,
сохраняя всё, что Telegram положил в адрес (`#tgWebAppData=…`).

Зачем: двери приложения живут на домашних платах за Tailscale Funnel, и их
имена в России иногда режут по одному. Адрес входа при этом не меняется, и
старые кнопки в чате продолжают работать.

Список дверей — в `index.html`, он же в `/etc/miniapp-doors.conf` на плате.
Маркер `<meta name="myllm-entry">` проверяет бот перед тем, как поставить
адрес на кнопку — не удалять.

Публикуется как GitHub Pages из ветки `main`.
